10. Practice Exercises

  • Write a program that adds two numbers
  • Create a basic calculator
  • Check if a number is prime
  • Implement a Person class with properties and methods
  • Build a banking system with inheritance
  • Write an async file-processing example

11. Study Checklist

  • Understand variables, data types, and operators
  • Write and read basic if/else and loops
  • Use methods and classes correctly
  • Apply inheritance, encapsulation, and polymorphism
  • Handle exceptions gracefully
  • Use LINQ and async/await effectively
  • Follow naming, structure, and testing best practices
